## How to use RootGuard

1. Read the article's **scope and prerequisites** before copying commands.
2. Identify the required **telemetry, permissions, and product versions**.
3. Treat queries without validation evidence as **examples**, not production detections.
4. Follow the referenced triage and remediation workflow.
5. Confirm outputs and record local findings. Sanitise customer and employer data before sharing.
